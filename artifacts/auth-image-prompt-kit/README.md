# Waddeh Auth Image Prompt Kit

This kit contains detailed prompts for generating the three desktop slideshow images used on the Waddeh auth page.

Recommended output:

- Format: JPG or PNG
- Size: 1400 x 1800 px
- Aspect ratio: 7:9 portrait
- Style: premium product/editorial image, Arabic-first, calm, focused
- Important composition rule: keep the lower 30% visually quiet because the auth page overlays the slide label, headline, subhead, and dots there.

Use `waddeh-auth-image-prompts.md` for copy-paste prompting.
Use `waddeh-auth-image-prompts.json` if you want structured prompts for an image generation workflow.

Important: the images should not contain large readable marketing text. The auth page already renders localized Arabic/English text over the image.
